Global caps remain3px adjacent/planted horizontal contact,2px vertical sole motion,6px adjacent shoe width change, and3% body-scale residual (contact values normalized to312px display width).

- Insular: exposed hero shoes, fixed visitor shoe/plan witnesses, fixed hinge attachment seam, gate free end, grip proximity. The moving gate is subtracted via its own per-cel measurement background so it is not mistaken for the exposed far shoe
- Shackle: strict planted contacts, exact reviewed far-shoe full outline, both visible grips, fixed exposed chain spans and attachments. A short chain portion overlaps the far toe. No hidden full-span visibility, link topology or physical tension is certified
- Cumbersome: strict contacts and exact reviewed far-shoe full outline, both supporting hands, carpet end and projected jamb-face clearance. The carpet overlaps the inner jamb in the foreground; no successful passage or hidden3D contact is certified
