# Core002 independent additive guard

This extension preserves all 60 reviewed guard files for the first 20 scenes byte-for-byte. The only accepted order is 175–189,4477,4688,2524,4011,2295,3510,581,3305,4608,3404. Canonical IDs and display ordinals are separate.

Run from any complete checkout with Python3, NumPy, Pillow and ffmpeg:

    python qa/core002-registration/run_suite.py --root . --report core002-suite.json

Or just the exact-media gate:

    python qa/core002-registration/check_batch.py --root . --report core002-gate.json

The gate binds exact video/poster bytes, decoded frame0 equality, frame count, configurations, review evidence, native dialogue and immutable prior guards. Numeric limits remain 3px adjacent/whole-cycle horizontal contact displacement, 2px sole displacement, 6px adjacent shoe-width change, at312px display scale, and3% body-height range. Whole-cycle tests include seam. Independent background references measure hero feet and body silhouette; they are not animation construction layers.

3305/4608 far shoes use complete exposed heel/toe bounds, midpoint, full silhouette width and supported soleY because curved bottom rows make sole-band centroid/width unstable. No hidden-edge permission applies. Both edges and full width remain guarded. Other hero feet use sole-band contacts. Static companion feet in3510/4608/3404 use tight fixed full-shoe raster witnesses, not sole-band ground-contact inference. All visible feet are accounted for.

Per-cel grip/prop witnesses supplement contact/scale bounds without normalizing away foot motion. Fixed references guard companions' shoes. Disingenuous hidden-shard frames check visible concealment boundaries only. Deplete checks visible cyan-water presence/absence and soil-rim endpoints; exact volume, hidden stream continuation and fluid physics are not measured. Native overlays and narrative interpretation remain independent visual review.

The suite includes correctly rehashed/review-bound synthetic media and mutations of each actual decoded scene: shifted/erased/widened hero shoes, shifted/erased static-shoe and prop witnesses, plus deplete upright-water, missing-stream and soil-miss cases. Positive reencoded controls must pass before mutation rejections count. No hash rejection is counted as geometry detection. All 60 prior files are individually tampered with in temporary test roots to verify immutable policy rejection.

This does not claim publication, continuous human-like visual perception, physical fluid simulation, or physical-iOS testing. Independent visual reports record the observation basis and remaining scope.
